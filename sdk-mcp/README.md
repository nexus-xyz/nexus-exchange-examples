# Track 2 — MCP server

Whole apps and agent setups built on
[`nexus-exchange-mcp`](https://github.com/nexus-xyz/nexus-exchange-mcp) — an agent
that trades or analyses markets through the MCP tool surface.

| Example | What it does |
| --- | --- |
| [`risk-review`](./risk-review) | Reviews one account against exposure, loss and margin limits over the MCP tool surface, with an explicit read-only allowlist. |

Adding one? See [CONTRIBUTING.md](../CONTRIBUTING.md). One example per directory:
`sdk-mcp/<example-name>/`.
