# The whole dependency set, every version pinned by `==`, per CONTRIBUTING § 3.
#
# There is no lockfile format here to commit, so this file has to be one: a pin
# on `nexus-exchange` alone is not reproducible, because its transitive tree
# would still float and a reader a year from now would get different bytes than
# the README describes. So the SDK's dependencies are pinned too, at the versions
# this example was verified against.
#
# Self-contained on purpose: no `-r`/`-c` includes, no `-e`, no alternate index.
# The `==` pins are only a guarantee if this file is the entire set.
